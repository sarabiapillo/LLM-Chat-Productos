¿Por qué usamos un archivo estático y no Vistas Blade de Laravel?
De acuerdo con el requerimiento de tu rúbrica sobre "Arquitectura Web y Consumo de Servicios", el sistema debe funcionar bajo una arquitectura Cliente-Servidor desacoplada. Si usáramos .blade.php, el servidor estaría renderizando HTML y manejando sesiones con cookies, rompiendo el modelo de API REST pura. Al usar un archivo cliente consumiendo datos exclusivamente por AJAX (Fetch) con un token JWT Stateless, garantizamos que cualquier frontend (React, Angular, Móvil o HTML puro) pueda conectarse al backend de manera agnóstica y 100% segura.
